# Correntra Downloader 0.1.0

Ilk Windows 10/11 surumu:

- cok parcalı HTTP/HTTPS indirme, duraklatma/devam, retry ve hiz siniri;
- Chrome/Edge MV3 uzantisi ile normal indirme devralma;
- korumasiz dogrudan medya, HLS, DASH ve oynatilan sosyal medya akislarini algilama;
- video kalite secimi ve ses cikarma/birlestirme altyapisi;
- Turkce ve Ingilizce profesyonel masaustu arayuzu;
- kategoriler, kuyruklar, zamanlama, toplu URL ve site baglantisi toplama;
- GitHub Releases tabanli guncelleme paketi;
- portable ZIP, setup EXE ve kaynak koddan `baslat.bat` akisi.

Netflix, Disney+ ve benzeri DRM/EME korumali akislar desteklenmez; koruma
atlatma uygulanmamistir.
