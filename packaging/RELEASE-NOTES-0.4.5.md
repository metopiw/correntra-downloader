# Correntra Downloader 0.4.5

New Correntra visual identity release.

## Öne çıkanlar

- Correntra'nın ana Windows uygulama ikonu, yeni turkuaz kolibri/ok tasarımıyla
  güncellendi.
- Kaynak kodu açmak için tek amaçlı **Correntra Baslat.exe** eklendi. EXE kendi
  yanındaki `baslat.bat` dosyasını çalıştırır; kaynak klasörünü elle terminalden
  açmaya gerek bırakmaz.

## Highlights

- The main Correntra Windows application icon now uses the new turquoise
  hummingbird/arrow visual identity.
- Added **Correntra Baslat.exe**, a single-purpose launcher that starts the
  adjacent `baslat.bat` for source-tree development.
