# Correntra Downloader

Kurulumdan sonra Correntra'yi acin. Chrome veya Edge uzantisini kurmak icin
uygulama klasorundeki `UZANTI-KURULUMU.txt` belgesini izleyin.

Uygulama hesap veya Correntra sunucusu gerektirmez. Guncelleme denetimi yalniz
GitHub Releases uzerinden yapilir. DRM korumasi asilmaz.
